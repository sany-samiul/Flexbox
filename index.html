Learning CSS Flexbox

A simple responsive webpage demonstrating Flexbox layout and navigation.

What is Flexbox?

Flexbox is a CSS layout system used to arrange elements inside a container. It makes it easier to create flexible and responsive web pages.

Flexbox is especially useful when we want to arrange elements in a row or column and control their size, spacing and alignment.

How the Content is Laid Out

The boxes below are arranged using Flexbox. The parent element uses display: flex, which makes its child elements flexible.

HTML

HTML provides the structure and content of the webpage.

CSS

CSS controls the appearance, spacing and layout.

Flexbox

Flexbox controls how the elements are positioned inside their container.

Important Flexbox Settings

Several CSS properties are used to control the Flexbox layout:

display: flex

Turns an element into a Flexbox container.

flex-direction

Controls whether items are arranged in a row or column.

justify-content

Controls the horizontal distribution of items.

align-items

Controls how items are aligned across the cross-axis.

flex-wrap

Allows items to move onto a new line when there is not enough space.

gap

Adds space between Flexbox items.

How the Layout Responds to Screen Size

The webpage is responsive, which means that the layout changes depending on the size of the screen.

On a large screen, the navigation menu appears horizontally and the Flexbox items can appear next to each other. On a smaller screen, the navigation menu becomes vertical and the content boxes can move onto new lines.

This is achieved using flex-wrap and a CSS media query.

Flexbox Features and How to Use Them

1. Flexible Layout

Items can grow or shrink depending on the available space.

2. Easy Alignment

justify-content and align-items make alignment easier.

3. Responsive Design

Flexbox works well with different screen sizes.

4. Wrapping

flex-wrap allows items to move to another line.
